# Example data
`seed_demo.csv` is an illustrative molecule, **not** the actual `qm9_0023` seed or a trained model.
`iteration1_validation.csv` and `model_metrics.csv` reproduce the numerical summaries reported during the project and are for plotting and documentation. They are not computational input datasets and do not include the underlying QC outputs.
Run `python scripts/plot_examples.py --out figures` to generate figures without xTB or ORCA.
