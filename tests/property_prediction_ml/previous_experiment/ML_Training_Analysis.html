MolCurator ML prediction of xTB gaps

Local experiment on a prospective 1000-molecule sample. 21 October 2026.

1000 molecules attempted; 948 successfully labelled; 52 failures retained. The validation-selected structure-only model achieves random-holdout MAE 0.407 eV, compared with 1.592 eV for the mean baseline (74.4% lower MAE). Its target is the output of our FF → xTB predictor, not an experimental or DFT property.

Data and calculation protocol

The local QM9_smiles.txt contains 133,015 nonempty rows. After connected neutral closed-shell checks, exclusion of the previous 336 structures, and deduplication without stereochemistry, 107,040 unique identities remained. A uniform seeded sample of 1000 was selected before labelling. Failure rows are not replaced with easier molecules.

Each label uses the public molcurator.tools.predict function: 30 ETKDGv3 conformers, seed 42, MMFF94 optimization, unique-minimum clustering at 0.25 Å, the lowest converged FF energy geometry and a GFN2-xTB single point. Temperature is 298.15 K; timeout is 120 s. A single-geometry fallback is attempted for an empty ensemble. No ORCA calculations were performed.

Calculation audit: 948 electronic launches, including 948 xTB and 0 ORCA; 0 cache hits. One candidate was explicitly retried after a transient preparation-record replacement failure, before any electronic launch for that entry. Candidate summary bookkeeping was reconstructed from verified geometry and log evidence; 416 individual end-to-end timings are unavailable after recovery, so those missing timings are not used for speed comparisons.

Splits features and model selection

Random splits aim at 70% training, 15% validation and 15% test. The grouped experiment keeps exact nonstereochemical Murcko scaffolds disjoint; all acyclic molecules belong to a single group. Group-size balancing uses no property labels. The scaffold split is stricter, but does not remove every form of structural similarity.

partition split test train validation
random 143 663 142
scaffold 140 666 142

Structure features are chiral radius-2 Morgan fingerprints (2048 bits) plus 13 simple molecular descriptors. The FF ablation adds selected FF energy, sampled weight, and unique/converged conformer counts. The data table also retains HOMO, LUMO and dipole values for future work. None of these xTB results is an input feature for the gap model. The structure-only predictor requires no geometry or external electronic program at inference.

Hyperparameters and the deployed structure-only model family were selected on validation MAE. Each chosen configuration was refitted on training plus validation data, then evaluated once on its held-out test. Scaling was fitted only within the relevant development data. The five predeclared families are shown together; the best-looking test number was not used to choose deployment.

Reuse in MolCurator

The selected structure-only model is structure_trees, saved under models/random/. A portable fingerprint-ridge JSON model is also provided. The local adapter returns one Prediction per candidate with its original ID, explicit failures and xyz_path=None. Successful ML predictions do not supply geometries for ORCA: selected candidates must run through physical PREDICT first to obtain validated XYZ.

python predict_ml.py --model models/random/structure_trees.joblib   --input generated.csv --output ml_predictions.json

# Portable ridge alternative
python predict_ml.py --model models/random/fingerprint_ridge.json   --input generated.csv --output ml_ridge_predictions.json

generated.csv requires id,smiles. Install Python 3.11+, RDKit, NumPy, scikit-learn and joblib; requirements.txt records the tested versions. The exported model was trained on the documented development subset, with the final test held out. Models are not automatically installed into the shared root train() stub.

Failed geometry candidates

The saved model also supplies 52 estimates for the preparation-failed inputs in analysis/unlabelled_failed_ml_estimates.csv. They have no xTB reference label and no XYZ. These estimates demonstrate geometry-free inference, but their accuracy cannot be measured here, and they cannot be sent directly to ORCA. Their original physical failure remains explicit.

Verification and timing

The CLI predictor reproduces saved held-out values, portable JSON reproduces the fitted ridge values, and mixed valid/invalid/radical/charged inputs preserve ID order and failures. No inference electronic calls were made. Full feature-plus-prediction time for 143 held-out molecules was 0.157 s, excluding 0.676 s model loading. This is a local diagnostic timing, not a production throughput guarantee.

Limits and next work

This is a small neutral closed-shell QM9-like chemical space, with failed preparation cases excluded from the regression target. It does not validate large conjugated emitters, radicals, net ions, solvents, excitation energies or TADF. Predictions and nearest-neighbour scores are not calibrated uncertainty. Test results depend on one predeclared seeded split; a broader repeated-split or prospective study would be needed for stronger generalization claims. Before production use, retain physical xTB/ORCA checks for selected or unfamiliar candidates and agree on agent-side ML screening thresholds.
