MolCurator repeated splits uncertainty and abstention

22 October 2026. Local extension of the 1000-molecule experiment using its 948 successful xTB labels. No new electronic calculations and no Git publishing.

Five repeats give MAE 0.498 ± 0.026 eV for random splits and 0.517 ± 0.062 eV for scaffold splits. These are means and sample standard deviations across seeds, not confidence intervals or independent external experiments. The original 0.407 eV result was a favorable random partition. Hyperparameters were fixed from the earlier study; this is a repeatability analysis of that configuration, not a new unbiased model-family benchmark.

Experimental design

Each seed changes the partition and ExtraTrees random state. The frozen model uses 160 trees, minimum leaf size 1, max_features 0.7, and the same 2048-bit chiral Morgan fingerprints plus 13 descriptors. The primary repeat model fits 85% and tests 15%, matching the earlier final development size. A second model fits approximately 65%, reserves 20% solely for interval calibration and tests on the same 15%. Calibration data are never used to fit that second model. Grouped partitions keep exact Murcko scaffolds disjoint across proper fit, calibration and test; all acyclic molecules form one group. Group-size balancing does not inspect labels.

Calibration and observed coverage

For absolute split conformal, calibration scores are |y − prediction|. The order statistic is ceil((n_cal + 1) × nominal coverage), with no interpolated quantile. Normalized scores divide the residual by the fitted ensemble standard deviation, floored at 0.10 eV. The deployed model uses the normalized method selected before testing. A group-max comparator instead takes the largest normalized residual within each calibration scaffold before forming its quantile.

The normalized nominal 90% intervals covered only 87.7% of random-test molecules and 89.3% of scaffold-test molecules on average. Absolute nominal 90% intervals reached 91.5% and 87.1% respectively. These methods were not switched or retuned after seeing test outcomes. Calibration is an estimation procedure, not proof that every tested or future subset has the nominal coverage. Coverage after acceptance filtering can differ further.

Exchangeability assumptions matter. Molecule-wise calibration does not establish conditional coverage for unfamiliar scaffolds, nor for a subset selected by an abstention rule. Scaffold groups also vary in size and composition. The group-max comparator is a conservative diagnostic; its formal group-level assumptions are not established by this dataset. The report therefore gives measured molecule and complete-group coverage separately.

Default abstention policy

A valid molecule is routed to physical PREDICT if any rule fires: an unseen scaffold; fingerprint similarity below max(0.25, the fit-only leave-one-out 10th percentile); heavy-atom count outside the fitted range; an element absent from fitting scope; a nominal 90% interval half-width above 1.0 eV; or a negative gap estimate. The 1.0 eV limit is an explicit operational tolerance, not a calibrated error bound. Invalid, radical or net-charged inputs go to input review because the existing physical backend also does not support them.

The strict unseen-scaffold rule means 100% of the scaffold holdouts are routed to physical prediction by construction. No accepted-scaffold-subset accuracy is claimed. On random splits the policy accepts 23.8–35.7% of candidates, averaging 32.2%. The accepted subset has mean MAE about 0.313 eV, versus about 0.615 eV for the routed subset. These conditional scores are descriptive and do not prove calibrated selective coverage; accepted normalized 90% coverage averaged about 86.9%.

Using the local router

router.py returns an explicit route and reasons for every original ID. Abstained rows retain a diagnostic ML estimate and interval, but accepted_ml_value_ev is null. They cannot silently be used as accepted ML predictions. No XYZ is created by ML. Physical execution requires an explicit flag and nonnegative molecule budget; ORCA is never called automatically.

python router.py --model models/random_calibrated_router.joblib   --input routing_example.csv --output routes.json

# Opt in to physical PREDICT for at most ten routed molecules
python router.py --model models/random_calibrated_router.joblib   --input generated.csv --output hybrid_results.json   --run-physical --physical-budget 10 --xyz-dir physical_run/xyz

Physical execution requires the installed MolCurator package and configured xTB executable. Budgets count selected physical candidates; exact expensive launches remain in the physical tool's durable attempt records. Remaining routed candidates are marked budget_deferred. The model is not refitted on calibration data after interval fitting. The shared project train() stub and main branch remain untouched.

Verification and scope

Sixteen deterministic checks verify separation of fit/calibration/test, exact 90% and 95% quantile ranks, interval nesting, familiar acceptance, unseen/size/wide-interval abstention, invalid-input review, ID/order preservation, absence of accepted values on abstention, physical budgets, and physical callback identity/count guards, and malformed/duplicate batch IDs. Exported routers also reproduce all 287 first-seed held-out predictions, intervals and routing decisions. Only mocked physical callbacks were used. Test predictions, split manifests, per-seed metrics, protocol, verification and models accompany the report.

The corpus remains small neutral closed-shell QM9-like molecules. Intervals target the xTB teacher rather than ORCA or experimental properties. Repeated seeds do not replace a prospective collaborator dataset or validate large conjugated emitters. The current default is deliberately conservative; it is an auditable prototype for ML triage rather than a certified confidence system.
